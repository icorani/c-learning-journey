- в Си все передается по значению
- переменная - это имя, адрес, тип, значение
- чтобы функция мняла оригинал - передаем ?x, функция принимает int *
- копия аргумента живет в стек-фрейме вызываемой функции
- функция вернулся - стек-фрейм уничтожен - копия исчезла
- стек один на процесс.
- есть стек ядра для системных вызовов
- каждый вызов функции = новый фрейм в том же стеке.
